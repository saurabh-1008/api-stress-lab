# Changelog

## 0.1.0

- Add a YAML-configured async HTTP load-testing CLI.
- Report latency percentiles, throughput, status codes, and transport failures.
- Evaluate expected statuses and optional latency, error-rate, and RPS thresholds.
- Generate terminal, JSON, and HTML summaries with request data redacted.
- Include a standard-library demo, GET/POST examples, user guide, and release guide.
- Package under the MIT license; archive original experiments under `legacy/`.
